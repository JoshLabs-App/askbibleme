## iOS Liquid Glass 视觉优化（2026-09-15 新增，待 Josh 决定）

方案与概念图：`docs/ios-liquid-glass-redesign.md`、`docs/design-concepts/2026-09-15-{home,read}-3directions.png`

1. **选哪条方向** —— 现状：三条方向（Glass as Instrument / Living Scripture / Native Quiet）已出文字方案 + 首页与阅读页并排概念图，未选。影响：不选就没法动代码，选错要返工整个壳层。需要 Josh 决定：挑一条（推荐 D1 主架构 + D2 的羊皮材质处理）。
2. **底栏是否降级** —— 现状：5 位 + 中央 60pt FAB + 36pt 图标。影响：改小/改成普通 tab 会动用户肌肉记忆，且与安卓/网页底栏分叉。需要 Josh 决定：是否接受改动。
3. **是否换 SF Symbols** —— 现状：iOS 用 MaterialIcons 字形，与 RN/安卓/网页共用字形表。影响：只换 iOS 会让四端图标语言分叉。需要 Josh 决定：分叉换 / 全端一起换 / 不换。
4. **deployment target 是否抬到 26** —— 现状 17.0。影响：抬了能删掉一半 fallback，但 iOS 17–25 用户拿不到新版。建议不抬，走「一套设计两套 renderer」。
5. **仓库里 328MB 构建产物** —— `apps/askbible-ios/build/DD`（DerivedData）。影响：占盘，纯本地产物可重建。需要 Josh 决定：是否现在删（我可以直接删，也可以等凌晨 3 点的清理脚本）。

### iOS Liquid Glass 第二轮新增待决（2026-09-16）

1. **底栏出现文字标签** —— 现状：换原生 TabView 后补了三语标签（首页/音乐/读经/圣经/探索），原来是纯图标栏。影响：底栏视觉更"系统"，但多一行字、信息密度变高。需要 Josh 决定：留标签（iOS 默认）/ 只留图标（要绕开系统默认行为）。
2. **iOS 图标语言与其它端分叉** —— 现状：iOS 已换 SF Symbols，RN / 安卓 / 网页仍是 MaterialIcons。影响：四端图标不再逐一对应，截图与文档要分别维护。需要 Josh 决定：维持分叉 / 后续把安卓网页也换过去。
3. **坞的展开方式** —— 现状：紧凑档点中间弹我们自己的矮 sheet。影响：不是原生 accessory 的上拉手势，和系统音乐的迷你播放器行为不完全一致。需要 Josh 决定：接受现状 / 下一轮改成原生上拉。
4. **要你在真机上确认一件事**：章页「划重点」画笔是否正常（手指划过经文能上色、能擦除）。这轮把其它纯控件弹层改成了玻璃，划重点条**故意没改**——它是唯一和下层 UIKit 画笔手势共存的浮层，模拟器的合成拖拽验证不出真实画笔行为。你在手机上划两笔，正常我就把它也改成玻璃，不正常我就知道这条路要绕。
5. **已关闭**：选哪条方向（定 D1+D2）、底栏是否降级（已降）、是否换 SF Symbols（已换）、deployment target 是否抬到 26（不抬，走两套 renderer）、底栏是否留文字标签（留）、坞展开方式（保持 sheet）、安卓网页何时对齐（等 iOS 定型）、`backgroundExtensionEffect`（评估后不做，理由见 redesign 文档第七节）—— 2026-09-15/16。

### 深色模式（2026-09-16 新增）

1. **iOS 深色模式与其它端分叉** —— 现状：iOS 跟随系统深浅色；RN / 安卓 / 网页仍只有浅色。影响：同一用户在 iPhone 与安卓上看到的不一样；Play / App Store 截图要分别准备。需要 Josh 决定：维持 iOS 独有 / 安卓也跟上 / iOS 加个「始终浅色」开关让用户自选。推荐：先观察 iOS 用户反馈，再决定安卓。
2. **深色下羊皮底纹的浓淡是品味问题** —— 现状：纸纹以 softLight 0.55 叠在 #1a1512 上，纹理能看出但很淡。影响：太淡像纯黑底，太浓像脏。需要 Josh 决定：手机上切深色看一眼，要更明显 / 更淡说一声（改一个数）。
