# 圣经人物博物馆系列｜统一生成标准

Josh 2026-09-11 在 ChatGPT 会话里逐轮调教后定下的版本，逐字存档。
以后出人物立绘**只报人物名 + 时期**，不再重新讨论风格。

配套：

- 代码里的英文风格锁：`lib/figures/scene-style-guide.ts` 的 `CHARACTER_PORTRAIT_STYLE_PROMPT`（场景配图用，与本文同源）
- 出图与取图操作流程：`~/Desktop/APP/01AI 短剧/docs/CHATGPT-出图流程.md`

## 一、整体视觉风格

所有人物保持完全一致的艺术风格：高质量 3D 圣经动画电影角色风格，写实与动画结合，精致但不照片写实，具有电影级角色设计质感。人物看起来像真实存在的圣经时代人物，但经过统一的动画艺术化处理。

**统一的是画风，不是脸。**

## 二、构图必须统一

正面、直立、站稳、全身、居中。

- 人物身体正对观众
- 头部保持正直，不歪头、不明显侧头、不明显仰头或低头
- 双肩基本水平，身体不要倾斜
- 双脚完整出现，自然分开、稳定站立
- 从头顶到脚底完整显示，人物垂直居中
- 每个人物占画面高度大致相同，给头顶和脚底留一致的安全空间
- 不裁切手、脚、衣服或道具
- 最终能够把很多人物并排摆在一起

**镜头（2026-09-11 补）**：

- 镜头高度与人物眼睛平行，平视观众
- 禁止仰拍，禁止从下往上的视角
- 禁止电影场景式构图
- 人物正面，或至多轻微的三分之二侧身

最终视觉应该像：一整排圣经人物站在博物馆展厅中，每个人都是独立的人物展品。而不是每个人都像电影海报里的动态角色。

## 三、透明背景

纯透明背景 / Alpha Channel / PNG cutout。

不要：博物馆、房间、建筑、山、沙漠、天空、地面、台座、背景墙、背景光晕、其他人物、动物、场景、文字、边框。

只要全身人物，不要场景。100% 透明 / Alpha，人物从头到脚完整显示。

人物本身有柔和的立体光影即可，但不能出现环境背景。

## 四、眼神统一，但表情不统一

所有人物眼睛看向正前方的观众，让人产生「这个圣经人物正在看着我」的感觉。

但表情根据人物自己的经历设计，不能所有人都笑：

| 人物 | 表情基调 |
|---|---|
| 大卫 | 成熟、温和，带王者和诗人的气质 |
| 扫罗 | 威严、紧张、复杂 |
| 摩西 | 沉稳、疲惫、坚定 |
| 亚伯拉罕 | 慈祥、智慧、经历丰富 |
| 约瑟 | 成熟、自信、克制 |
| 耶稣 | 平静、慈爱、深邃 |
| 马利亚 | 年轻、温柔、谦卑 |

眼睛看观众是统一的，情绪是人物自己的。

博物馆展品般的陈列感，但人物本身是有生命、有情绪的，不是蜡像。

## 五、动作不能统一

绝对不要求每个人都伸手。动作必须根据人物身份决定。

可以：双手自然垂下、双手交握、一只手自然放在身体旁边、双手放在腰间、手持符合身份的物品、手持武器、抱着物品、轻微自然姿态。

但必须满足：站得稳、站得直、正面、适合与其他人物并排。不要为了「有动作」而让人物摆夸张姿势。

## 六、每个人必须是完全不同的脸

硬性规定。同一个 3D 动画风格，但绝对不能出现「同一个人换衣服」的感觉。每次重新设计人物脸部。

必须重新考虑的**骨相**：脸型轮廓、额头宽窄、眉骨、眉毛形状、眼型、眼睛大小、眼距、鼻梁、鼻头、鼻翼、颧骨、下颌、下巴、脸部肉感、年龄感。

必须重新考虑的**外貌**：发型、发量、发质、胡须、肤色、脸部皱纹、身材、身高、体格。

不能简单通过改变头发或胡子来制造人物差异，必须从脸部骨相开始重新设计。

## 七、人物身份决定服装和道具

不能为了画面漂亮而给所有人塞一个杖。每个人的「时代 + 身份 + 职业 + 圣经记载 + 所处人生阶段」决定服装、道具和气质。

## 已确定的 7 个角色

### 1. 大卫王
**时期**：壮年为王，统一以色列并以耶路撒冷为都城时期。
**脸**：偏方的圆脸；年轻但成熟、饱满有肉感；浓密眉毛、眉尾上扬；大而明亮的眼睛、眼距略宽；挺直但偏短的鼻梁、圆润鼻头；方正有力的下颌角；嘴角天然微微上扬。
**外貌**：中等偏高、健壮；红润面色；深金棕色微卷中长发；修整胡须；武士锐气 + 诗人柔和。
**服饰**：深紫红色王袍、金线织纹、白色细麻长衣、王室斗篷、镶饰皮带、朴素金冠、装饰皮靴。
**道具**：竖琴可以保留，这是大卫非常重要的身份特征。
**姿态**：不要夸张伸手，正面直立、王者般稳定站立。

### 2. 扫罗王
**定位**：以色列第一位王。
**外貌**：明显高大、宽肩、强壮、成熟男性；比大卫更粗犷；深色头发、浓密胡须。
**脸**（必须与大卫完全不同）：更长更宽的脸；强烈眉骨；深陷眼窝；较窄眼距；更长的鼻子；强烈下颌；更厚重的脸部结构。
**气质**：威严、强势、武士感，同时带有内在的不安和复杂感。
**服装**：王室服装 + 战士元素；深红 / 暗金 / 棕色；皮革和金属；王冠。
**道具**：剑、矛等可以出现，但不是强制动作。

### 3. 摩西
**定位**：出埃及、旷野时期。
**脸**：年长；长脸；明显眉骨；深邃眼睛；较长鼻子；高颧骨；瘦削但坚毅；深皱纹。
**外貌**：年老；长而波浪状的灰白头发；很长的灰白胡须；风霜感；经历巨大人生压力后的脸。
**气质**：庄严、疲惫、坚定、智慧。
**服装**：米白色亚麻长袍；红棕色 / 深褐色披肩；编织腰带；沙漠旅行风格；简朴皮凉鞋。
**道具**：手杖可以出现，杖有很强的身份意义。但不要出现第三只手、额外手臂或多余道具。

### 4. 亚伯拉罕
**定位**：族长时期。
**脸**（和摩西要明显不同）：更宽的脸；饱满的面部；高额头；宽眉；温和的大眼睛；宽而圆润的鼻子；柔和的下颌；年老但慈祥。
**外貌**：白灰色长胡须；灰白头发；年老；有族长的厚重感。
**气质**：慈祥、智慧、温厚、经历丰富。
**服装**：米白色长袍；棕色 / 土红色披肩；编织腰带；头巾；皮革包；凉鞋。
**姿态**：自然站立即可，不需要一定伸手。

### 5. 约瑟
**特别注明**：雅各的儿子，**埃及宰相时期**。约瑟不能画成普通希伯来牧人。
**脸**（与大卫 / 扫罗 / 摩西完全不同）：椭圆偏窄脸；高额头；细长眉；较大的杏仁形眼睛；鼻梁直而窄；下颌比较平滑；年龄感约成年男性。
**气质**：聪明、克制、成熟、自信，有行政官员的威严。
**服装**：明显埃及高级官员风格——白色细麻长衣；蓝色和金色；宽大的埃及项饰；腰带；埃及官员披肩；金饰。但不要让他看起来像「法老」。
**姿态**：正面稳定站立，双手自然，不需要王者式夸张动作。

### 6. 耶稣
**时期**：约三十岁，开始公开传道。要避免画成前面任何一个男人。
**脸**：中等偏长脸；温和但有力量的面部轮廓；中等额头；自然眉形；深邃但平静的眼睛；鼻梁自然；下颌适中；面部不过度英雄化。
**外貌**：约 30 岁；中东犹太人外貌特征；深棕色中长波浪头发；短而整洁的胡须。
**气质**：不是王、不是战士、不是英雄海报人物，而是平静、慈爱、坚定、深邃，有非常强的内在力量。
**服装**：米白 / 象牙色长袍；简单红棕色披肩；编织腰带；简单皮凉鞋。
**姿态**：直立、双手自然，不要默认伸手。

### 7. 马利亚
**时期**：拿撒勒少女时期。
**脸**（必须明显区别所有女性角色，并且明显年轻）：年轻少女脸；柔和椭圆脸；饱满但不成熟；高额头；自然细眉；较大的杏仁形眼睛；眼距自然；小而柔和的鼻子；圆润下巴。
**外貌**：拿撒勒年轻犹太女子；深棕色长发；一部分头发被头巾覆盖；年轻、纯真。
**气质**：谦卑、温柔、安静、坚定。
**服装**：米白色长袍；蓝色披肩；简单编织腰带；白色头巾；棕色凉鞋。
**姿态**：正面站直，双手自然交握在身前即可。

## 最终统一模板

以后每一个人物都按这个底层模板：

```text

高质量3D圣经动画电影风格。
写实与动画结合。
精致、自然、具有电影级角色设计质感。

单人物。
全身。
头顶到脚底完整可见。
正面站立。
身体垂直。
头部保持正直。
双肩自然水平。
双脚完整并稳稳站在地面位置。
人物居中。
与其他人物保持统一的画幅、比例和人物高度。

人物双眼直视正前方的观众。
具有与观众交流的眼神。
表情根据人物自己的年龄、经历、身份和性格设计。

不要统一人物动作。
不要默认伸手。
不要默认微笑。
不要默认拿手杖。
姿态和道具必须根据圣经人物身份决定。

每个人必须重新设计完全不同的脸。
禁止沿用前一个人物的脸。
重新设计脸型、额头、眉骨、眉形、眼型、眼距、鼻型、颧骨、下颌、下巴、年龄感、发型和胡须。
人物之间必须具有明显的身份和骨相区别。

透明背景。
PNG Alpha Channel。
没有环境。
没有地面。
没有背景墙。
没有博物馆建筑。
没有其他人物。
没有文字。
没有边框。
没有裁切。

最终视觉效果：
像博物馆中一组可以并排陈列的圣经人物，
每个人独立站立，
正面面对观众，
风格统一，
但每个人都有完全独立的脸、身份、服饰、年龄和气质。
```

## 每次发送的前缀块（2026-09-11 Josh 定版，逐字复用）

出图时**每一条都要带上这整段**，末尾直接加人物名 + 时期。不要只报名字，ChatGPT 会漂。

```text
统一系列风格：

高质量3D圣经动画电影角色风格，明显的动画人物而非真人写实；大而有神的眼睛，简洁且有设计感的五官，柔和圆润的造型，哑光/半哑光材质，温暖电影级光影。

全身完整站立，头到脚全部可见，人物居中，镜头与人物平行、自然人眼高度，正面或轻微侧身，眼睛直视观众，产生"这个人物正在与参观者交流、好像有话要说"的生命感和博物馆展品感。

每个人必须重新设计完全不同的脸，根据人物自己的年龄、身份和骨相设计：脸型、额头、眉骨、眉形、眼型、眼距、鼻型、颧骨、下颌、嘴型都必须明显不同，绝不沿用其他人物的脸。

姿态、手势和道具不固定，根据人物的圣经身份、时代和故事自然设计；不要机械地伸手、拿杖或摆相同姿势。

真正透明背景，输出真实Alpha透明PNG。背景必须完全透明，绝对不要绘制棋盘格、灰白方块、背景、地面或阴影。

禁止写实照片感、真人感、写实CGI、皮肤毛孔和过度真实皮肤纹理。
禁止低角度仰拍，人物不要仰望镜头。

生成：<人物名 + 身份 / 时期>
```

**为什么要每条都发**：只报人物名时，会话上下文会被前面的图带偏——风格从动画漂成真人写实，透明底变成画上去的棋盘格。这段前缀把两个坑都写死了。
