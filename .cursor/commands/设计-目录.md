# 设计技能目录（AskBible）

在输入框打 **`/`** 选下面任一简写；或在 **`@`** 里搜同名项目技能。

| 简写 | 用途 |
|------|------|
| `/设计-默认` | 日常改 UI（taste-skill v2） |
| `/设计-安静` | 安静编辑风（minimalist）— **产品面首选** |
| `/设计-改版` | 先审计再改版（redesign） |
| `/设计-高端` | 更精致、偏 agency 感（soft） |
| `/设计-动效` | 强动效营销页（gpt-taste，慎用主产品） |
| `/设计-完整` | 代码不要被截断（output） |
| `/图-App` | App 屏概念图，不写代码 |
| `/图-Web` | 网站 section 参考图，不写代码 |
| `/图-品牌` | 品牌板 / Logo 方向图 |
| `/图-转码` | 有参考图 → 按图实现 |
| `/设计-v1` | taste-skill 旧版行为 |
| `/设计-Stitch` | Google Stitch DESIGN.md |

**记忆口诀：** 改产品用 **安静** 或 **改版**；只出图用 **图-***。

请告诉我要做哪一项，或直接发 `/设计-安静` 等命令。
