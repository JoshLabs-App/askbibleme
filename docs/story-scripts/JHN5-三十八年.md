# 三十八年 —— 共读《约翰福音》第五章
对谈稿 · 中文 · 约 6 分半 · **平等交流型**（两位主持人对等，不是师生问答）

角色：小满（女）／老周（男）——两个一起读书的人，谁都可以起话头、谁都可以反问。

> **表述约定**（Josh 2026-09-19）：为避开国内平台对信仰类内容的审核，稿中一律用「这本书」「书上说」「这一卷」「这段记载」代替「圣经」「经文」；用「读者」代替「信徒」；口吻是共读一部古代文献，谈文本本身的张力与结构，不作布道。文本里引用到的原话照引，人名照用。

**小满**：老周，我们今天读的这一段，开头就有一句特别怪的话。有个人在池子边上躺了三十八年，来了一位，问他：「你要痊愈吗？」——躺了三十八年的人，还用问他要不要好吗？

**老周**：我第一次读也觉得这句是废话。后来发现，关键不在这句问话，在那个人的回答。他没说「我要」。

**小满**：对，他答的是：「先生，水动的时候，没有人把我放在池子里；我正去的时候，就有别人比我先下去。」

**老周**：你看他这三十八年是怎么过的——盯着那池水，等它动，然后跟人抢。他整个盼望都押在一个先到先得的机制上，还得有人帮忙。问他要不要痊愈，其实是在问：你有没有想过，你缺的可能根本不是运气和帮手。

**小满**：这个三十八年，我查了一下，还真不是随手写的数字。

**老周**：你是说旷野那段？

**小满**：嗯。同一本书前面记载，以色列人在旷野漂流，从加低斯巴尼亚到过撒烈溪，正好是三十八年。写这一卷的人下笔很省，很少写闲笔。一个躺在门边、进不去的人，躺了三十八年——这个画面本身就在说一个民族的处境。

**老周**：而且接下来那句话很短——「起来，拿你的褥子走吧」，人就好了。我注意到这里**没有**的东西比有的东西更值得说：这个人没求过他，没有任何表态，甚至根本不知道对方是谁。书上专门写了一句，「那医好的人不知道是谁」。

**小满**：说实话，这人后面的表现挺让人别扭的。

**老周**：你也这么觉得？他被盘问，转头就把人供出去了。文本里一句夸他的话都没有。我觉得不必把他读成一个榜样——这一段要立的根本不是他，是那位说话的人的身份。

**小满**：冲突点也特别小，就是「安息日不能拿褥子」。

**老周**：这里有个细节值得说清楚：「安息日不可拿褥子」并不是那本律法书的明文，是后来的宗教传统加出来的细则。所以场面就成了——一个躺了三十八年的人站起来走路，在场的人看见的却是：有人违规了。

**小满**：然后他回了一句，「我父作事直到如今，我也作事」。这句话我一直没太明白为什么会引发那么大的反应。

**老周**：这句话是整章的转轴。你要知道当时的宗教学者自己有个共识：那一位在安息日并没有停工，他仍然托着万有、仍然施行审判、仍然施恩，不然世界当天就停摆了。他们承认有这么一个例外。

**小满**：所以他说「父作事，我也作事」——

**老周**：他把自己放进了那个只属于一位的例外里面。

**小满**：在场的人听懂了吗？

**老周**：下一句写得明明白白：他们越发想杀他，因为他「不但犯了安息日，并且称神为他的父，将自己和神当作平等」。这里我想停一下——有一种常见的说法是，他从来没有自称过什么，都是后人加上去的。可是当场要动手的那批人显然不这么认为。他们不是听岔了才发怒，是听懂了才发怒。

**小满**：接下来那一大段讲父和子的话，说实话有点绕。

**老周**：绕，但是极其平衡。一边说：「子凭着自己不能作甚么，惟有看见父所作的，子才能作」——这是彻底的顺服，不自作主张。另一边说：「父所作的事，子也照样作」——凡那边作的，这边都作。

**小满**：听着像是既低一头，又平起平坐。

**老周**：后来的读者一直是这样理解的：在差遣和职分上是顺服的，在本质和权能上是同等的。而这段话具体点出了哪两件事呢？一是叫死人活过来，二是审判所有人。这两样在前面那些书卷里，从来只属于那一位，没有第二个能分。

**小满**：然后就是那句——「叫人都尊敬子如同尊敬父一样。不尊敬子的，就是不尊敬差子来的父。」

**老周**：这句话把一条很多人想走的路给堵死了：我敬重那位至高者，但把这个人只当成一位了不起的老师。按他自己说的，这条路走不通。

**小满**：不过这一章里我最喜欢的其实是后面那一句，「那听我话、又信差我来者的，就有永生；不至于定罪，是已经出死入生了」。

**老周**：注意那个时态——不是将来出死入生，是**已经**。判决在当下就下了，不是等到最后才揭晓。

**小满**：后半章他列了好几重见证。

**老周**：因为按当时的规矩，一个人为自己作证不算数，得有两三个人的口。所以他列了四重：一位先行者的见证、他自己所作之事的见证、差他来者的见证，还有这本书本身。前三重讲完，最后一重最扎人。

**小满**：您是说那句「你们查考这经」？

**老周**：原话是：「你们查考圣经，因你们以为内中有永生；给我作见证的就是这经。然而，你们不肯到我这里来得生命。」这话是对谁说的？是对当时全国最熟这本书的那批人说的。他们逐字抄、逐字背，为一个字母能争半天。可是这整本书指着的那一位站在面前，他们不肯挪那一步。

**小满**：也就是说，读这本书这件事本身，居然可以变成一种阻挡。

**老周**：当读书变成目的本身的时候就会。他没说不要读，他说的是这本书是**为他作见证**的——是一根指路的手指，不是终点。眼睛停在手指上，就永远到不了它指的地方。这句话放到今天也一样成立：读了多少年、能背多少句，和有没有往那边走一步，是两回事。

**小满**：最后他还提到了摩西。

**老周**：「有一位告你们的，就是你们所仰赖的摩西。你们如果信摩西，也必信我。」他们最拿来当靠山的那个人，反倒成了控告他们的。整章就这么从一池水、一张褥子，一路讲到审判席前面。

**小满**：那我们就用那两句收尾吧。

**老周**：「给我作见证的就是这经。然而，你们不肯到我这里来得生命。」——愿我们读完了，肯往前走那一步。
