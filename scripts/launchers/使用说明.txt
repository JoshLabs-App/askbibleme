Selah.my Studio — 双击启动（仅 macOS）

位置：本文件夹里的三个 .command 文件

1-开发服务器.command
  → 日常写代码用。会打开终端并运行 npm run dev
  → 浏览器打开：http://localhost:3450/studio

2-卡住时重启.command
  → 页面打不开、报 chunk/缺文件 等异常时用。会先释放 3450 端口并 clean 后重启

3-检查能否编译.command
  → 改完代码点一次，自动做类型检查 + 构建。有错会在窗口里显示

首次双击若提示「无法打开」或安全警告：
  在文件上 右键 → 打开 → 仍要打开

不要移动 .command 文件到项目外，否则无法找到项目目录。
