## 已修复

| 优先级 | 问题与触发 | 修复后的行为 |
| --- | --- | --- |
| P1 | 登出或换账号后，先前发出的登录、刷新、校验或读经同步请求稍后返回，可能恢复旧会话或写入旧账号数据。 | 两个原生端按会话代际校验异步结果；Web 按当前认证所有者取消过期同步与界面更新。 |
| P1 | Web 换账号时可能将上一账号的本地读经数据合并上传到新账号；换号拉取后仍可能继续执行上传。 | 强制先执行账号隔离和拉取；过期请求不能继续写入，拉取分支完成后返回。账号隔离在任何网络等待之前执行；离线未上传进度按账号归档，原账号回来后恢复，删除成功才丢弃对应归档。 |
| P1 | 原生删除账号先清本地进度，服务端删除失败时数据已经丢失。 | 请求成功且仍属于当前会话后才执行本地清理；失败保留进度。 |
| P2 | 账号切换没有真正清除持久化的重点标记；iOS 仅有重点标记或成就时不被视为有待同步数据。 | 清除对应存储而非只清显示状态；识别上述游客进度。 |
| P2 | 并发 token 刷新、等待者取消或同时修改昵称可能丢失已经轮换的新凭据。iOS 昵称竞态已复现五个断言失败。 | 合并同一凭据的刷新请求，保留服务器已轮换的 token，同时保留刷新期间修改的昵称。 |
| P2 | HTTP 429 / 5xx 的短暂刷新故障被视为凭据永久失效，触发错误登出。 | 两个原生端按可重试网络故障处理，明确拒绝的刷新仍使旧凭据失效。 |
| P2 | Android 下载响应可能是 HTML、部分响应或截断 SQLite，并替换原来可用的经文库。 | 检查 HTTP 状态、长度与 SQLite 头/页数，以唯一临时文件下载，验证后原子替换；失败保留旧库。 |
| P2 | Web 登录回跳只检查字符串前缀，反斜杠、控制字符或路径规范化可以绕过预期。 | 登录页、Google / Apple 按钮和 OAuth 回调统一校验；在 URL 规范化前拒绝危险拼写，规范化后核对同源和登录循环路径，保留正常站内深链。 |
| P2 | Web 快速切换读经计划时，旧请求可能覆盖新选择；背景接口失败可能产生未处理异常。 | 异步结果只应用到仍有效的请求；请求失败保留已有可用背景。 |
| P2 | 浏览器存储额度已满时，归档或退出元数据写入抛错，可能中断个人进度清除。 | 存储失败不能阻止账号隔离；当前标签页保留归档和所有者状态，清理腾出空间后重试持久化。完全禁止存储时，仅当前标签页可恢复该归档。 |
| P3 | 子页面已经拼接产品名，根布局又套标题模板，浏览器标签出现两次 AskBible.me。 | 统一使用产品名称真源，只拼接一次；应用和电视页面一并对齐。 |

## 验收证据

- iOS：独立 XCTest runner 编译实际原生源码，12 项测试通过；原生 App 模拟器 Debug 构建通过。入口 `apps/askbible-ios/Tests/run-account-isolation.sh`；测试不访问真实账户，使用隔离的 UserDefaults 与受控 HTTP 响应。昵称竞态先红后绿。
- Android：`:core:test :app:compileDebugKotlin` 通过，21 项核心测试，零失败；下载回归使用本地 HTTP 响应与实际 SQLite 文件，刷新失败分类使用本地 HTTP 400/429/500/503。
- Web：71 个 Vitest 文件、327 项测试通过（含存储额度边界 2 项先红后绿回归）；TypeScript 检查与本机 Cloudflare/vinext 生产构建通过。构建产物在 Workers 本地预览中验证首页、圣经目录、创世记、音乐、TV、下载共 6 页，均返回 200、无横向溢出、无未处理浏览器异常；翻到创世记第 2 章正常。音乐两首分别取得有效时长且播放进度实际前进，切歌、暂停、切换专辑通过；已查看手机读经/音乐及 1920×1080 电视截图。
- 下载页名称统一为产品真源，删除将产品描述成问答工具的旧文案。
- 页面网络观察：Supabase 的匿名连通性 HEAD 探针返回 401（现行实现有意只检查域名是否可达）；部分可选音乐能量分析 JSON 返回 404，既有占位动画正常，音频起播与切歌不受影响。
- 公共构建资源：已成功生成静态经文 1178 个文件、交叉引用 66 卷与信经正文。

- 既有重点标记合并差异仍未解决：Android 使用后写覆盖，iOS / TS 使用并集，擦掉的重点可能被旧云端副本恢复；空重点集合也存在不上报路径。见 `docs/OPEN-ITEMS.md`。本轮修复的是账号隔离时清除重点，两者不可混称。

- 原生代码已验证，尚未提交 App Store / Google Play 审核，不代表已安装用户已经获得更新。
