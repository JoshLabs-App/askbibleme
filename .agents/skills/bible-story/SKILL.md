Josh 自己听、自己测试用，**不进 App、不上 R2**。稿子入库，音频不入库。

| 东西 | 路径 | 入库？ |

命名里的版本：`-scripted`（照稿播）／`-free`（它自己发挥）。

## 一、取经文

```bash
sqlite3 -separator ' ' data/bible/sqlite/cuv-simp.sqlite \
  "select verse,text from verse where book_id='1KI' and chapter=13 order by verse;"
```

书卷 id 是三字母大写（`1KI` `1SA` `PSA` `MRK`…）。把相关的平行经文、诗篇标题、新约引用一并取出来——
这些往往就是解读的骨架（例：大卫装疯要配诗34、诗56 的标题；铜蛇要配约3:14）。

⚠️ sqlite 原文里 `〔……〕` 是译者夹注，念出来很怪，写稿引用时清掉；全角 `（）` 里的（诗篇标题、「细拉」）是正文，保留。

## 二、写稿：这是整个流程里最值钱的一步

**Josh 要的是正统、有深度的释经，不是心灵鸡汤，不要现代自助式励志。**
NotebookLM 自由发挥拿不到这个深度，所以稿子必须自己写。

固定两个角色：

- **晓恩**（女，主持，代表听众发问，负责把读者心里的「这公平吗」「这不矛盾吗」说出来）
- **陈老师**（男，讲解，给释经）

写稿要点（从已完成的两集里总结的，照着做）：

1. **开场用听众真实的不适感切入**，不要用「今天我们来学习……」。
2. **先给历史与文本背景**，尤其是紧邻的上一章——很多故事的钥匙在前一章（王上13 的钥匙在王上12 耶罗波安另立敬拜）。
3. **找出叙事者自己埋的记号**：重复的句子、刻意的沉默（经文不作评价本身就是信息）、反常的细节（狮子不吃尸身、大卫带着歌利亚的刀进歌利亚的城）。
4. **立一到两根神学柱子**，用旧约律法或新约书信作检验，不要停在道德教训。例：申13:1-5 与加1:8 检验「新启示」；神的话的有效性不系于传讲者的表现。
5. **主动堵住两种误读**：律法主义（活在恐惧里）和廉价恩典（清楚的命令可以商量）。
6. **结尾做基督论对照**，简短、不牵强。
7. **落到一节经文收尾**。
8. 语气庄重温和、有牧养心肠；引经文说出处；不要猎奇和戏谑。

**长度换算**：中文约 **250 字/分钟**。4-5 分钟 ≈ 1100-1300 字；10 分钟 ≈ 2500 字。
Josh 没说长度就默认做 **4-5 分钟**的短集。

## 三、生成音频：NotebookLM

音色自然度上 NotebookLM 明显赢过 edge-tts 和 Kokoro（Josh 2026-09-18 盲听结论），所以默认走它。

**Josh 没特别说的话，两个版本都做**，让他对比：

- **A 照稿版**：来源 = 写好的逐字稿；指令 = 严格照稿播。
- **B 自由版**：来源 = 经文 + 中立背景资料（**不要放自己的解读**，否则对比没意义）；指令 = 只要求正统深度、不要鸡汤，角度它自己定。

### 操作步骤（内置浏览器，登录态常在）

1. `preview_start` 打开 `https://notebook.google.com`。
2. 「+ 新建」建笔记本 → 弹窗里点「**复制的文字**」→ `find` 拿到 placeholder 为「在此处粘贴文字」的 textbox → `form_input` 灌内容 → 点「插入」。
   **用粘贴，绝对不要碰「上传文件」**，文件选择器在自动化里会卡死。
3. 顶部切到 **Studio** → 点「音频概览」卡片右侧的 `>` 打开自定义面板。
4. 面板里设三样：格式「**深入探究**」（默认已选）、语言「**中文（简体）**」、时长 **短** 或 **默认**。
   ⚠️ **时长只认这个开关，不认指令里写的分钟数**。实测：「短」≈ 6 分钟，「默认」≈ 11-16 分钟。
   指令里写「总长控制在四到五分钟」它照样给 6 分钟出头。要更短只能自己剪，或者把稿子写得更短。
5. 往下滚，在「**AI 主持人在本集节目中应着重于哪些方面？**」里写死指令（A/B 两版的指令模板见下）→「**立即生成**」。
6. 等 **6-16 分钟**（短的快些）。**用后台 sleep 等，不要用截图轮询**（贵）。查状态：
   ```js
   document.body.innerText.includes('正在生成音频概览') ? 'generating' : 'ready'
   ```
7. 好了以后点卡片右侧 `⋮` 展开菜单，**停在这里，请 Josh 点「下载」**（见下一节）。

### 指令模板

**A 照稿版**：
> 来源是一份已经写定的节目逐字稿，请严格照着它播，不要另起炉灶。一、保留稿中两位主持人的分工：女声担任「晓恩」（主持、发问），男声担任「陈老师」（讲解）。二、按稿子原有顺序把每个环节讲到：<把本集的关键环节逐条列出来>。三、不要加入稿子里没有的观点、例证、类比或现代生活应用，不要发散。四、语气庄重温和、有牧养心肠，语速从容，避免综艺式的插科打诨和夸张语气词。五、总长控制在 N 分钟。

**B 自由版**：
> 面向有一定圣经基础的华语基督徒听众，做正统、有深度的释经，不要心灵鸡汤，不要现代自助式励志。请紧扣来源里的经文本身展开，可以自由决定切入角度和结构。语气庄重、温和、有牧养心肠，语速从容，避免综艺式的插科打诨和夸张语气词。引用经文时说明出处。总长控制在 N 分钟。

## 四、下载必须 Josh 亲手点（这条绕不过去）

浏览器面板只允许**用户自己的点击**打开新标签，Codex 点必定被拦（提示「新标签页被拦截」，而且确实没下下来）。

所以流程是：**把 `⋮` 菜单展开摆好 → 在回复里请 Josh 点「下载」 → 他点完说一声 → 从 `~/Downloads/<音频标题>.m4a` 取。**

两个版本就请他点两下（先摆一个，他点完再切到另一个笔记本摆第二个）。

**已经验证过走不通的，不要再试**：

- 给页面挂 `window.open` / `HTMLAnchorElement.prototype.click` 钩子去捕获下载地址 —— 钩子会把**真实下载也一并拦掉**，连 Josh 自己点都失效，必须刷新页面才恢复。
- 直接 fetch 音频地址 —— 在 `lh3.googleusercontent.com`，跨源被 CORS 挡。
- `navigate` 到该地址 —— 内置浏览器不允许导航到该域。
- `curl` 那个地址 —— 拿回的是 Google 登录页（900KB HTML，`content-type: text/html`，很容易误判成音频，记得 `file` 一下）。
- 用 Codex in Chrome 下 —— Josh 的 Chrome 登录的是**另一个 Google 账号**，看不到这些笔记本。

## 五、取回与归档

```bash
# ~/Downloads 不在项目内，第一次要先 request_directory 申请访问
ffmpeg -v error -y -i ~/Downloads/<标题>.m4a -ac 1 -ar 24000 \
  -codec:a libmp3lame -b:a 48k private/bible-stories/audio/<BOOK><CH>-scripted.mp3
```

31.8MB → 5.7MB，听感够用。转完把 `~/Downloads` 里的 m4a 删掉（一次性产物）。
然后用 `SendUserFile` 发给 Josh 试听。
