# 成就系统：ChatGPT 评审 + Claude 的判断（2026-09-18）

会话：ChatGPT「圣经应用成就系统优化」。发过去的是本项目已实现的成就 / XP 设计全文。

## ChatGPT 的核心判断

> 现在最大的风险不是「游戏化不够」，而是「把属灵行为过度量化」。
> 让系统奖励「回来、坚持、深入、与人同行」，而不是奖励「刷得更多」。

它给的四条边界：**奖励完成，不奖励点击；奖励坚持，不惩罚失败；记录旅程，不制造竞争；纪念意义，不制造刺激。**

### 它建议保留的
读完一章的反馈、66 卷书卷印章（「强烈保留」，说这是整套里最有仪式感、且与圣经内容本身相关的东西）、章 +250 / 卷 +3000 / 计划日 +500、23 枚勋章（但降低存在感，当成「旅程收藏」而不是每日刺激）。

### 它建议改掉的（按它给的严重度）
1. **断签倍率掉回 1.0** —— 最该改。典型 loss aversion：连续 40 天后忙了一天掉回 1×，用户的感受是「我毁了」，接着是「那算了」。它主张改成**恩典式 streak**：月度参与天数日历（「本月与神相遇 18 天」）+ 每月 2 次 Grace Day，断一天不让前面失效；连续天数只给**纪念性称号**（7 天「一周同行」/ 30 天「一个月同行」/ 365 天「一年读经」），**不给经济利益**。
2. **每听 15 秒 +12 XP** —— 它建议直接删。理由是这一条只需要「播放」不需要「完成」，用户挂着不听也涨分，与要培养的行为没有对应关系。
3. **+XP 飘字 / 每节 +8** —— 建议弱化到不显示，XP 只在章完成 / 计划完成 / 里程碑出现。

### 它认为最值得做的下一步（按投入产出比）
1. ★★★★★ **恩典式 streak**（上面那条）
2. ★★★★★ **「我的读经旅程」页** —— 把 XP 降级成众多指标之一，主角换成「已完成 17 卷 / 已读 283 章 / 阅读 42 小时」和逐卷完成度列表。它认为这比再加 20 枚勋章更值得做，因为产生的是 Progress → Identity。
3. ★★★★☆ **同行计划** —— 和妈妈 / 配偶 / 小组一起读一卷，**只显示共同进度，不排序、不比较、不催促**（「我们已经一起读了 18 天」）。这是在不做排行榜的前提下补关系型留存。
4. ★★★★☆ **「为什么这节经文对我重要」** —— 收藏时让用户自己写一句话，几年后回看变成个人意义资产（「妈妈住院的时候，我一直想到这节」）。它特别强调**不要让 AI 替用户解释经文的意义**。
5. ★★★☆☆ **阶段性回顾** —— 7 / 30 天回顾读过什么，是反思不是奖励；**绝不能让系统做属灵判断**（不能说「你的信心正在增长」）。

## Claude 的判断：哪些采纳，哪些不采纳

**和 Josh 的要求直接冲突的一点**：Josh 明确要「XP 一直在涨、很多很多 XP」，ChatGPT 主张把 XP 降成后台。这必须由 Josh 拍板，我不替他决定。见 OPEN-ITEMS。

我的看法，分条：

- **「断签掉回 1.0」应该改，这条我完全同意，而且和 Josh 的要求不冲突。** 「XP 一直在涨」要的是**正反馈**，惩罚不是正反馈。恩典式 streak 照样能给 Josh 要的手感——把倍率改成**只升不降的「同行加成」**（读经天数越多加成越高，断了不掉，只是不再涨），既保留「老用户每个动作更值钱」的爽感，又去掉「我毁了」那一下。这是两全的。
- **「听读 XP」要改，但不是删。** ChatGPT 的担心是对的：挂着播放器也涨分。但删掉会砍掉 Josh 要的实时手感（听整章朗读的时候进度条在动，这正是最舒服的场景）。**更好的修法**：听读 XP 只在**前台且正在播放**时计，并且**每章封顶**（比如一章最多给章长对应的量），听完整章再给完成奖励。这样刷不动，手感还在。
- **「每节 +8 的飘字」我不同意删。** 这是 Josh 点名要的东西，而且它挂的是「真的滚过了这一节」，不是空点击。ChatGPT 把它和老虎机类比过头了——老虎机的核心是**随机**奖励，我们这里是**确定**奖励，心理机制不一样。真要降噪，做法是把飘字合并（已实现：连续的 +XP 会合并成一条），而不是取消。
- **「我的读经旅程」页我强烈同意，这是这次评审里最值钱的一条。** 而且我们已经有一半了（成就页的 66 卷印章墙就是它的雏形），补上逐卷完成百分比和累计数字就成型。
- **「同行计划」值得做，但不是现在。** 它要后端、邀请、权限，是一个独立的大功能，不该混进这一版。
- **「为什么这节经文对我重要」性价比极高**，收藏时加一个可选输入框而已，但留存价值可能超过再加二十枚勋章。这条我建议排在同行计划前面。
