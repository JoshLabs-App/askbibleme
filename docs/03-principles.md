# Principles（产品原则）

1. Reading First（阅读优先）
所有系统都必须服务于进入经文。

2. Journey Over Features（旅程大于功能）
产品核心是 Journey，不是工具。

3. Low Cognitive Load（低认知负荷）
用户必须轻松进入。

4. Companion Before Exploration（陪伴优先于探索）
探索是奖励，不是入口。

5. Gentle Return（温和回归）
用户回来不是因为任务，而是因为愿意继续。

6. Pull-based Depth（拉取式深度）
深度只在用户主动时展开。

7. Silence Matters（留白重要）
不能信息轰炸。

8. Tools Must Disappear（工具必须退后）
工具不能成为注意力中心。
